# Apollo Waypoints

Общие вейпоинты для сервера Apollo-tech. Точки хранятся на сервере и сами появляются у всех игроков в Xaero's Minimap и Xaero's World Map: на миникарте, в мире и на большой карте. Кто-то добавил или поправил точку — у остальных она обновляется сразу, без перезахода.

Minecraft 26.3, Fabric.

## Как это работает

Сервер хранит список точек и рассылает его игрокам, у которых стоит мод, а мод показывает их в Xaero отдельно от твоих личных точек:

- точки видны всегда, какой бы набор (set) ни был выбран в Xaero;
- они не записываются в личные файлы Xaero и не смешиваются с твоими точками;
- любую точку можно выключить только для себя, по одной или все сразу, и она останется выключенной после перезахода.

Если нужна копия у себя (например, чтобы видеть точки вне сервера), кнопка «В набор Xaero» копирует серверные точки в обычный набор Xaero «Apollo».

## Установка

**Сервер:** `apollowaypoints-<версия>.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) в `mods/`.

**Игрокам:** тот же jar, Fabric API и [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap). [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map) — по желанию, наши точки видны и там.

Зайти на сервер можно и без мода: работают команды `/wp` и кнопки в чате. С одним только Xaero можно брать точки себе кнопкой [Add] и отправлять свои на сервер через Share. Автоматически обновляемые точки на карте — только с модом.

Скачать jar: раздел [Releases](../../releases).

## Для игроков

**Экран мода** — клавиша **J** (меняется в настройках управления) или команда `/wpgui`. Там список всех точек с поиском, фильтрами по измерению и категории и расстоянием до точек рядом. Кнопки: добавить, изменить, удалить, телепорт, выключить для себя. Ещё три:

- «Из Xaero…» — отправить на сервер точки из своих наборов Xaero;
- «В набор Xaero» — скопировать серверные точки к себе;
- «Выключить все» / «Включить все» — сразу все точки из списка, с учётом поиска и фильтров. Например, можно выключить только точки незера.

**Выключить точки у себя.** Выключенная точка не рисуется на миникарте, в мире и на World Map, а в списке Xaero остаётся серой. Выключать и включать можно где удобно: в экране мода (по одной или все сразу), кнопкой «Выключить» в экране вейпоинтов Xaero или правым кликом по точке на World Map. Мод запоминает выбор, и после перезахода или рестарта сервера точки остаются выключенными. На сервере и у других игроков ничего не меняется. «Удалить» в Xaero для серверной точки тоже просто выключает её у тебя.

**Поделиться точкой из Xaero.** Нажми в Xaero «Share» на своей точке — сервер ответит тебе в чат кнопками категорий. Нажми нужную, и точка станет общей.

**Уведомления.** Когда кто-то добавляет точку, у тебя всплывает уведомление. Выключается кнопкой в экране мода.

## Команды

`<точка>` — имя (с автодополнением) или номер: `12` или `#12`. Русские имена с пробелами в конце команды пишутся без кавычек: `/wp add Железная ферма`. Если после точки идут ещё аргументы, удобнее номер, а имя тогда берётся в кавычки.

| Команда | Что делает |
|---|---|
| `/wp` | справка |
| `/wp add <имя>` | точка на твоём месте |
| `/wp add <x y z> <имя>` | точка по координатам (`~` работает) |
| `/wp list [категория] [страница]` | список с кнопками [ТП] [+X] [✎] [✖] |
| `/wp near [радиус]` | ближайшие точки: расстояние и стрелка относительно взгляда |
| `/wp info <точка>` | всё о точке и кнопки правки |
| `/wp set <точка> color <цвет>` | цвет (см. ниже) |
| `/wp set <точка> category <категория>` | категория |
| `/wp set <точка> symbol <1–2 знака>` | буквы на значке |
| `/wp set <точка> visibility local\|global\|map` | в пределах дистанции / всегда / только на карте |
| `/wp set <точка> yaw here\|none\|<градусы>` | куда смотреть после телепорта (удобно для AFK-точек) |
| `/wp set <точка> y none\|<y>` | убрать или задать высоту |
| `/wp set <точка> dimension <измерение>` | перенести в другое измерение |
| `/wp desc <точка> [текст]` | описание (без текста — убрать) |
| `/wp move <точка>` / `/wp move <x y z> <точка>` | перенести на твоё место / по координатам |
| `/wp rename <точка> <новое имя>` | переименовать |
| `/wp remove <точка>` | удалить в корзину (в ответе кнопка [Вернуть]) |
| `/wp trash`, `/wp restore <точка>` | корзина: точки лежат там 30 дней |
| `/wp history [точка]` | кто и что менял |
| `/wp share <точка>` | показать точку всем в чате; у кого Xaero — появится [Add] |
| `/wp get <точка>` | прислать точку себе с кнопкой [Add] для Xaero |
| `/wp tp <точка>` | телепорт |
| `/wp category list` | категории |

Цвета — те же 21, что в Xaero: `black`, `dark_blue`, `dark_green`, `dark_aqua`, `dark_red`, `dark_purple`, `gold`, `gray`, `dark_gray`, `blue`, `green`, `aqua`, `red`, `purple`, `yellow`, `white`, `magenta`, `light_blue`, `lime`, `pink`, `brown` (можно и по-русски: `золотой`).

Точка без высоты (`~`) при телепорте ставит на поверхность, а в незере — на свободное место под потолком.

## Для админов

| Команда | Что делает |
|---|---|
| `/wp category add <id> <название>` | новая категория (id — латиница, цифры, `_`) |
| `/wp category rename\|color\|visibility <id> …` | изменить категорию |
| `/wp category remove <id>` | удалить; её точки переходят в категорию по умолчанию |
| `/wp import <измерение> [категория] <файл>` | импорт файла вейпоинтов Xaero (например `mw$default_1.txt`) из `<мир>/apollowaypoints/import/` |
| `/wp export <измерение>` | выгрузка в формате файла Xaero в `<мир>/apollowaypoints/export/` |
| `/wp reload` | перечитать конфиг |

Стартовые категории: Фермы, Порталы, Базы, Структуры, Прочее. Если у точки не выставлен свой цвет, она берёт цвет категории.

### Права

Права проверяются через API прав Fabric: если на сервере стоит мод прав (например LuckPerms), он решает сам, иначе используются уровни опа из конфига. С LuckPerms мод пока не проверялся.

| Право | По умолчанию |
|---|---|
| `apollowaypoints:use` — смотреть, list, near, info, history, share, get | все |
| `apollowaypoints:add` | все |
| `apollowaypoints:edit.own`, `apollowaypoints:edit.any` | все |
| `apollowaypoints:remove.own`, `apollowaypoints:remove.any` | все |
| `apollowaypoints:tp` | оп 2; в режиме наблюдателя — все |
| `apollowaypoints:admin` — категории, импорт, экспорт, reload | оп 3 |

Править и удалять любые точки по умолчанию могут все, поэтому есть корзина и журнал: удалённое возвращается через `/wp trash`, а в `/wp history` видно, кто что менял.

### Конфиг

`config/apollowaypoints.json` создаётся при первом запуске:

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `permissions` | см. таблицу выше | уровень для каждого права: `all`, `moderators`, `gamemasters`, `admins`, `owners` или число 0–4 |
| `tpInSpectator` | `true` | телепорт к точкам для всех в режиме наблюдателя |
| `maxWaypointsPerPlayer` | `0` | лимит точек на игрока, 0 — без лимита |
| `trashDays` | `30` | сколько дней хранить удалённые точки |
| `shareMode` | `prompt` | Share из Xaero в чате: `off` — не трогать, `prompt` — предлагать добавить, `prompt_and_hide` — предлагать и не пускать строку в общий чат |
| `announceInChat` | `false` | писать в общий чат о новых точках |
| `defaultCategory` | `misc` | категория для точек без категории |
| `defaultVisibility` | `local` | видимость новых категорий |

### Где лежат данные

- `<мир>/apollowaypoints/waypoints.json` — точки и категории. Прошлая версия лежит рядом в `waypoints.json.bak`. Если файл не читается, мод его не перезапишет: изменения отключатся, опам при входе придёт сообщение.
- `<мир>/apollowaypoints/history.jsonl` — журнал изменений.
- У игрока: `config/apollowaypoints-client.json` — выключенные точки и настройка уведомлений.

## Совместимость

Проверено с Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.161.0+26.3, Xaero's Minimap 26.5.3 и Xaero's World Map 1.46.4. Если новая версия Xaero окажется несовместимой, мод напишет об этом в чат и перестанет рисовать точки, а список и команды продолжат работать.
